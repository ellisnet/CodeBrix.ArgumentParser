CodeBrix.ArgumentParser is a fully managed, cross-platform command-line
option parser for .NET. It is a direct fork of the Mono.Options library,
version 6.12.0.148, adapted to the CodeBrix family conventions. This file
is intended to be a single, authoritative source for every third-party
copyright, license, and provenance notice that applies to source code
(and any other non-source assets) that has been incorporated into this
repository from other open-source projects.

NuGet package dependencies consumed at build time or test time — for
example xUnit, SilverAssertions, coverlet.collector, Microsoft.NET.Test.Sdk —
are NOT covered by this file. Each such package ships with its own
license and its own third-party notices; this repository does not
redistribute any of their source code.

Every .cs source file in this repository that was derived from an
external project carries the original upstream copyright header verbatim
at the top of the file, and its `namespace` declaration line is
annotated with `//was previously: <upstream.namespace>;` so the
provenance of each file is unambiguous.

to you under the terms set forth in the LICENSE file, which is located
at the root of this repository.

1.3  Notable modifications during port

     For transparency, the following material changes were made during
     the port from upstream Mono.Options 6.12.0.148 to
     CodeBrix.ArgumentParser:

       * Conditional-compilation branches removed. The upstream source
         contained `#if PCL`, `#if !PCL`, `#if LINQ`, `#if NDESK_OPTIONS`,
         `#if TEST`, `#if NETSTANDARD1_3`, and `#if !PCL || NETSTANDARD1_3`
         blocks. Only the .NET-10-relevant branches were kept.

       * `[Serializable]` + `ISerializable` + `SecurityPermission`
         scaffolding on `OptionException` was dropped, because .NET binary
         serialization was deprecated in .NET 8+.

       * The root namespace was changed from `Mono.Options` to
         `CodeBrix.ArgumentParser` (with sub-namespaces under that root).

       * Source organisation changed from one monolithic Options.cs file
         to a sub-folder / sub-namespace layout (see 1.1 above).

       * Nullable-reference-type annotations (`string?`, etc.) and the
         null-forgiveness `!` operator were not introduced, per the
         CodeBrix family convention of NRT-off codebases.

       * XML doc comments were added to every public (and unsealed-
         protected) member to satisfy `<GenerateDocumentationFile>`.

       * Tests that asserted on exact .NET Framework BCL exception-message
         strings (e.g. `"Parameter name: prototype"`) were either rewritten
         to assert on exception type only, or omitted, because modern .NET
         BCL formats those messages differently.
